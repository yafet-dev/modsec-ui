# WAF Administration Documentation

Welcome to the Zergaw WAF Administration Documentation. This documentation is designed for organization owners and administrators to help you effectively manage and govern your Web Application Firewall.

## 📚 Documentation Structure

### Available Guides

- **[Overview](./overview.md)** - High-level summary of all WAF management features and capabilities
- **[Dashboard Guide](./dashboard.md)** - Complete guide to using the Dashboard for monitoring and managing your WAF
- **[Logs Guide](./logs.md)** - Comprehensive guide to viewing, filtering, and analyzing security event logs
- **[Users Guide](./users.md)** - Quick guide to managing team members and access control
- **[Settings Guide](./settings.md)** - Complete guide to WAF settings, IP bans, geo access, and notifications

### Coming Soon

- Security Rules Configuration (Super Admin only)

## 🎯 Purpose of This Documentation

This documentation focuses on **administrative and operational** guidance rather than technical implementation details. It's designed to help you:

- Understand how to use each feature of the WAF management portal
- Make informed decisions about security configurations
- Monitor and respond to threats effectively
- Govern your organization's security posture
